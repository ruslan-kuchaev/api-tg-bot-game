# API TG Bot Game

Телеграм-бот для отслеживания обновлений игр. Бот проверяет новости/патчи игр (через Steam API и/или другие источники) и позволяет вручную запускать проверку и просматривать список отслеживаемых игр.

## Стек
- Язык: TypeScript
- Рантайм/фреймворк: Node.js + grammy
- Ключевые зависимости:
  - grammy — библиотека для создания Telegram-ботов
  - dotenv — загрузка переменных окружения
  - @grammyjs/conversations — диалоги (в проекте установлен)
  - @neondatabase/serverless — опциональная зависимость для работы с БД (Neon/Postgres)

## Структура проекта
```
package.json         # npm-скрипты (dev, build, start)
tsconfig.json
.env.example         # пример переменных окружения
games.json           # список / конфигурация отслеживаемых игр
src/
  bot.ts             # точка входа — регистрирует команды и ловит ошибки
  types.ts           # типы контекста и сессии
  commands/
    start.ts         # обработчик /start
    check.ts         # обработчик /check — запуск проверки обновлений
    listGames.ts     # обработчик /listgames — показать игры
    index.ts
  menu/
    botmenu.ts       # описание команд для Telegram (setMyCommands)
  utils/
    configLoader.ts      # загрузка конфигурации / env
    steamApi.ts          # вызовы Steam API / логика получения данных
    updateChecker.ts     # логика сравнения и обнаружения обновлений
    messageFormatter.ts  # форматирование сообщений для отправки пользователям
```

Как это работает (кратко)
- `src/bot.ts` запускает бота, подключает сессии и регистрирует команды `/start`, `/check`, `/listgames`.
- Список игр хранится в `games.json`.
- Модуль `updateChecker` использует API (например, Steam через `steamApi.ts`) для получения данных и сравнения с сохранённой информацией в сессии/памяти. При обнаружении изменений формируется сообщение через `messageFormatter` и отправляется пользователю.

## Установка и запуск
1. Клонируйте репозиторий и установите зависимости:

```bash
git clone https://github.com/ruslan-kuchaev/api-tg-bot-game.git
cd api-tg-bot-game
npm install
```

2. Создайте `.env` на основе `.env.example` и задайте необходимые переменные окружения:
- `API_KEY` — токен Telegram-бота (обязательно).
- `STEAM_API_KEY` — API-ключ Steam (если используется).
- Другие переменные (опционально): параметры подключения к БД, если вы планируете использовать Neon/Postgres.

3. Для разработки (с авто-перезапуском при изменениях):

```bash
npm run dev
```

4. Сборка и запуск в продакшн:

```bash
npm run build
npm run start
```

## Команды бота
- `/start` — приветствие / начальная настройка
- `/check` — принудительно запустить проверку обновлений игр
- `/listgames` — показать список отслеживаемых игр

## games.json
Файл `games.json` содержит конфигурацию и список игр, которые бот проверяет. Изменяйте или расширяйте его, чтобы отслеживать новые игры.

## Сохранение состояния
В текущей реализации состояние (последние проверки и найденные обновления) хранится в сессии (`session` мемо) — это не будет сохраняться между перезапусками процесса. Для долговременного хранения добавьте интеграцию с БД и сохранение данных из `gameUpdates`.

## Отладка и логирование
- В `src/bot.ts` есть базовый обработчик ошибок (Grammy / HTTP / Unknown). Для локальной отладки используйте `npm run dev` и добавляйте логи в `updateChecker`/`steamApi`.
